## Học theo trình tự

1. Đọc tình huống và mục tiêu; tự dự đoán trước khi xem kết quả.
2. Làm ví dụ nhỏ bằng tay, nối công thức với hình và ý nghĩa dữ liệu.
3. Mở notebook, chạy từng ô theo thứ tự và kiểm chứng với dữ liệu thật.
4. Viết một điều kết quả chứng minh được và một giới hạn.
5. Chuyển sang dự án có TODO khi đã học đủ kiến thức tiên quyết ghi trong dự án.

## Chạy thực hành

Cài Python theo [hướng dẫn chung](../../docs/START_HERE.md). Từ thư mục gốc:

```bash
python -m jupyterlab course/bai06/Bai06_Thuc_hanh.ipynb
python course/run_labs.py --lesson 6
```

Lệnh tự động chạy notebook và kiểm chứng khoa học nếu có. Notebook đã chạy lưu trong `outputs/`; bảng và kết quả tham chiếu tại bài học có thể được tính lại. Dùng bản sao repository nếu muốn giữ nguyên các tệp tham chiếu.
